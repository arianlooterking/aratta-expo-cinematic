# Aratta Expo Cinematic

Standalone Next.js redesign for Aratta Expo / شرکت توسعه تجارت اَرَت.

## Commands

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 9090
npm run lint
npm run typecheck
npm test
npm run build
```

## Product Boundaries

- Persian is primary (`/fa`) and English has parity (`/en`).
- Current public exhibition dates are before May 26, 2026, so events are archived until a fresh calendar is supplied.
- Registration is an inquiry/download flow. The form creates an email draft and does not fake backend submission.
- Official forms/downloads remain linked to `arattaexpo.ir`.

## Implemented Surface

- Scroll-linked cinematic booth-build hero with reduced-motion fallback.
- Liquid-glass nav, language toggle, mobile drawer, exhibition archive, services tabs, official downloads, inquiry form, gallery lightbox, news archive, contact section, sitemap, robots, and JSON-LD.
- Dedicated related-news section for industry coverage, workshops, video/interview archive, and Aratta-adjacent exhibition updates.
- Admin panel at `/admin` for bilingual content editing, local draft storage, JSON export, and production publish handoff.
- Local QA screenshots are in `qa/` when generated by verification scripts.

## Staff Portal

The Exhibition Hall Operations Command Center is available at **/fa/staff** and **/en/staff**. It includes an interactive hall canvas, metric rulers, adjustable grid snapping, a complete plan-element library, collapsible navigation, a narrow-first booth inspector, booth-level equipment requirements, delivery/pickup scheduling, issue handling, run-of-show tasks, capped activity history, validated JSON/CSV import, reference-image tracing, and a strict occupancy-only public hall export.

The current staff portal is a functional local-first operations slice. Its sample records contain no private contacts, and edits are saved only in the current browser. Multi-user sync, real staff authentication, role enforcement, database persistence, signed file storage, and transactional audit logs are intentionally **not** claimed or simulated.

Before using private exhibition data, add and review the approved auth/database foundation described in **docs/aratta-staff-portal-blueprint.md**. The staff routes are marked noindex and excluded through robots.txt, but that is not access control.

## Admin Publish Backend

The admin panel never writes production content by pretending. It supports local edits and export immediately; production publishing requires server-side configuration:

```bash
ADMIN_WRITE_TOKEN=
ADMIN_CONTENT_WEBHOOK_URL=
ADMIN_CONTENT_WEBHOOK_TOKEN=
```

`ADMIN_CONTENT_WEBHOOK_URL` should point to a secure CMS, GitHub Action, deploy workflow, or backend that persists the submitted content and triggers review/deploy.

## Known Launch Note

`npm audit --audit-level=moderate` currently reports nine transitive advisories: the Next.js internal PostCSS advisory plus development/build-tool advisories through Vite, Wrangler, Miniflare, esbuild, undici, and ws. npm offers non-forced updates for several build-tool paths, while its forced PostCSS remedy would install an old breaking Next.js version. Review and test dependency upgrades deliberately; do not run the forced fix blindly.
